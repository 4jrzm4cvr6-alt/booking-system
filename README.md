# Booking System Website

A simple, modern booking system website built with HTML, CSS, and JavaScript.

## Features

✨ **Core Features:**
- Create new bookings with service selection
- Store bookings in browser's localStorage
- View all your bookings in a clean card layout
- Cancel bookings with confirmation
- Responsive design for mobile and desktop
- Real-time form validation
- Success notifications

## How to Use

1. Open `index.html` in a web browser
2. Fill in your details:
   - Full Name
   - Email
   - Phone Number
   - Select a Service (Haircut, Massage, Dental Checkup, Consultation)
   - Choose a Date and Time
   - Add optional notes
3. Click "Book Appointment"
4. Your booking will appear in the "Your Bookings" section
5. Cancel any booking by clicking the "Cancel Booking" button

## Technologies Used

## Data Storage

Bookings are stored in the browser's localStorage, which means:
- Bookings persist even after closing the browser
- Data is stored locally on your device
- Clearing browser data will delete bookings
